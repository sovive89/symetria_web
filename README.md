# Nova Platform

Crie uma aplicação web SaaS profissional, moderna e responsiva.
Objetivo:
Construir uma plataforma com interface limpa, experiência de usuário simples e arquitetura preparada para crescimento.
Requisitos gerais:
Utilizar design moderno, minimalista e profissional.
Criar interface responsiva para desktop, tablet e celular.
Usar componentes reutilizáveis.
Criar navegação clara com menu lateral e dashboard.
Aplicar boas práticas de UX/UI.
Preparar estrutura para autenticação de usuários e controle de permissões.
Stack desejada:
Frontend moderno com React/Next.js.
TypeScript.
Tailwind CSS.
Componentes organizados e escaláveis.
Banco de dados preparado para integração com Supabase/Firebase.
Funcionalidades iniciais:
Sistema de usuários:
Cadastro e login.
Perfil do usuário.
Controle de acesso por tipo de usuário.
Dashboard:
Resumo das principais informações.
Cards com métricas.
Gráficos intuitivos.
Área de notificações.
Gestão de dados:
Criar telas CRUD completas.
Cadastro, edição, visualização e exclusão.
Busca e filtros.
Paginação quando necessário.
Experiência:
Loading states.
Mensagens de erro amigáveis.
Validação de formulários.
Feedback visual das ações.
Estrutura do projeto:
Organize o código pensando em evolução futura:
components
pages/routes
services
hooks
database
utils
types
Crie dados fictícios para demonstração inicial.
Priorize:
Código limpo.
Segurança.
Performance.
Escalabilidade.
Interface com aparência de produto comercial pronto para lançamento.
Antes de implementar, analise a melhor arquitetura e apresente a estrutura planejada do projeto.
